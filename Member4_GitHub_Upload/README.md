# Member 4 — CBM Classification & Evaluation

## 1. Overview

This module implements the classification and evaluation components of our Concept Bottleneck Model (CBM) on the CUB-200-2011 dataset.

The classifier takes 312 predicted concept probabilities generated by Member 2's Concept Bottleneck Layer (CBL) and predicts one of 200 bird species.

The main responsibilities of this module are:

- Train a Concept-to-Class classifier.
- Evaluate bird species classification performance.
- Evaluate concept prediction performance.
- Save the best classifier and evaluation results.
- Provide a baseline for future comparison with Localization-Guided and Quality-Aware CBMs.

## 2. Model Architecture

The classification pipeline is:

```text
Bird Image
    ↓
CLIP ViT-B/32
    ↓
Concept Bottleneck Layer (Member 2)
    ↓
312 Continuous Concept Probabilities
    ↓
Linear Classifier (312 → 200)
    ↓
200 Bird Species Logits
    ↓
Predicted Bird Species
```

The classifier consists of a single linear layer:

```python
classifier = nn.Linear(312, 200)
```

The model is trained using Cross-Entropy Loss and the Adam optimizer.

## 3. Input Data

The classifier uses the concept predictions provided by Member 2.

Required files:

```text
concept_scores/
├── concept_predictions_train.pt
├── concept_predictions_val.pt
└── concept_predictions_test.pt
```

Each file contains:

- `concept_probs`: Continuous concept probabilities (312 concepts)
- `class_labels`: Bird species labels (0–199)
- `concept_targets`: Ground-truth concept labels
- `concept_predictions`: Binary concept predictions

The classifier uses `concept_probs` as input and `class_labels` as the classification target.

Dataset splits:

| Split | Samples |
| --- | ---: |
| Training | 5,394 |
| Validation | 600 |
| Testing | 5,794 |

## 4. Training Configuration

| Parameter | Value |
| --- | --- |
| Model | Linear Classifier |
| Input Dimension | 312 |
| Output Dimension | 200 |
| Loss Function | CrossEntropyLoss |
| Optimizer | Adam |
| Learning Rate | 0.001 |
| Batch Size | 128 |
| Maximum Epochs | 100 |
| Best Epoch | 99 |
| Best Validation Accuracy | 53.33% |
| Training Device | CPU (Docker, Linux ARM64) |

The best classifier is selected based on validation accuracy and saved as `classifier_best.pt`.

### Run Training

From the project root directory:

```bash
python evaluation/train_classifier.py \
    --data-dir concept_scores \
    --epochs 100 \
    --batch-size 128 \
    --lr 0.001
```

## 5. Evaluation

The trained classifier is evaluated on the official CUB-200-2011 test split.

The evaluation includes:

- Top-1 Classification Accuracy
- Top-5 Classification Accuracy
- Classification Macro-F1
- Concept Micro-F1
- Concept Macro-F1
- Confusion Matrix

### Run Evaluation

```bash
python evaluation/evaluate.py \
    --data concept_scores/concept_predictions_test.pt \
    --checkpoint evaluation/results/classifier_best.pt
```
